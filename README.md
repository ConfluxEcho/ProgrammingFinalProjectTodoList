# Finální projekt
Tento projekt se soustředí na vytváření účinného a produktivního programu v podobě Todo listu (úkolovníku). Vytvoříme zde několik stran a následně je propojíme pomocí programovacího jazyka C#. Při tom budeme dbát na zásadní bezpečnosti a BOZP. Výsledkem by měl být plně funkční program, který zvládá vše, co na něj uživatel hodí (a k čemu je navržený).
